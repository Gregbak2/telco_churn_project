# Предсказание оттока телеком-клиентов (Telco Customer Churn)

## Описание проекта
Анализ базы клиентов телеком-провайдера и построение модели машинного обучения для предсказания оттока (Churn). 
Основная цель работы — выявить ключевые факторы ухода пользователей и оптимизировать алгоритм классификации так, чтобы максимизировать метрику Recall для снижения финансовых потерь бизнеса.

## Стек технологий
* **Язык:** Python
* **Библиотеки:** pandas, scikit-learn, matplotlib, seaborn
* **Инструменты:** Jupyter Notebook, VS Code

## Этапы исследования
1. **Предобработка данных:** Обработка скрытых пропусков (пустые строки в `TotalCharges`), приведение типов, One-Hot Encoding для категориальных переменных.
2. **Разведочный анализ (EDA):** 
   * Выявлен парадокс цены: уходящие клиенты в среднем имели более высокий чек.
   * Установлено, что самый массовый отток происходит в первый месяц обслуживания на контрактах "Month-to-month".
   * Доказано влияние отсутствия технической поддержки на вероятность расторжения договора.
3. **Машинное обучение:** 
   * Построена модель Логистической регрессии (`LogisticRegression`).
   * Решена проблема дисбаланса классов (74% / 26%) с помощью балансировки весов (`class_weight='balanced'`).
4. **Бизнес-оценка:** Доказана экономическая эффективность модели. Повышение Recall до 0.82 позволило выявлять подавляющее большинство уходящих клиентов, что в рамках юнит-экономики перекрывает потери от снижения Precision.

## Как запустить проект
1. Склонируйте репозиторий.
2. Убедитесь, что установлен Python 3 и необходимые библиотеки (см. стек).

4. Откройте и запустите файл с ноутбуком `.ipynb`.
